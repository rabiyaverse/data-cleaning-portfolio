# Public Health Data Cleaning Portfolio

## About

This repository showcases my developing skills in public health data cleaning, data organisation, research documentation, and spreadsheet-based analysis.
The projects use publicly available information and official Australian Bureau Statistics (ABS). They demonstrate my ability to organise data, apply consistent variable names, identify special values, document data limitations, and prepare datasets for further analysis.

## Projects

### Project 1: ABS Recorded Crime – Victims

This project uses published Australian Bureau of Statistics data on victims of family and domestic violence-related offences by sex from 2014 to 2024.

Skills demonstrated:

- Importing and organising official statistical data.
- Cleaning and restructuring spreadsheet data.
- Standardising column names and formats.
- Identifying and documenting special values such as `n.a.` and `n.p.`.
- Maintaining source notes and data limitations.
- Calculating proportions of total victims.
- Preparing data for trend analysis by sex and year.
