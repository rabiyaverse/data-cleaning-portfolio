# ABS Recorded Crime – Victims: FDV by Sex, 2014–2024

## Project overview

This project uses published Australian Bureau of Statistics (ABS) data on victims of family and domestic violence-related offences by sex from 2014 to 2024.

## Data-cleaning tasks

- Organised and restructured the ABS table.
- Standardised headings and labels.
- Checked year, sex, offence and jurisdiction fields.
- Preserved ABS values such as `n.a.` and `n.p.`.
- Documented data limitations and source notes.
- Prepared the dataset for descriptive analysis by sex and year.

## Important notes

- `n.a.` means data are not available or the calculation is not applicable because the denominator is zero.
- `n.p.` means data are not published.
- FDV assault data are not available for Victoria or Australia.
- FDV assault data are not published for Queensland before 2023.

## Source

Australian Bureau of Statistics, *Recorded Crime – Victims*, family and domestic violence-related offences, 2014–2024.

Source: ABS Recorded Crime – Victims.

This project uses publicly available aggregated data. No confidential or identifiable information is included.
